# WhatsApp Outreach Dashboard

Single-file dashboard for WhatsApp outreach. Upload a CSV or Excel list of leads, pick a template, and tap a button to open WhatsApp with the message filled in. You press Send yourself.

- Static site: `index.html` only, no build step.
- Lead data stays in your browser. Nothing is uploaded to a server.
- Deploy on Vercel by importing this repo (Framework Preset: Other, no build command).
